Decisions for the owner

Decided 2026-11-22. The owner answered: Approve all as recommended. All seven go as recommended below. The record is in the spec, §13.5, and item 7 is a follow-up in §17.

  1. Approve P1–P4 for one integrate PR. They go to main together, through the merge queue. The comments core (P4.9) is now on main. In this batch the bubble shows Comment, last and after a separator, only where comments are switched on, which is not the case on the web sandbox, so nothing changes there. P5, the bubble's comment icon, is a small follow-up after this batch, alongside the comments track's draft card (P4.10). Recommended: approve.
  2. A colour pick closes the colour menu. Enter, Space or a click on a colour row applies it, closes the menu, returns focus to the text with the selection kept, and announces the pick ("Red text"). The approved spec (O4) kept the menu open. Recommended: keep closing. It is one step shorter, and a second colour is one more click.
  3. The row's colour menu shows both columns, text and highlight. §7.3 asked for the column of the half you pressed. The bubble's menu does follow §7.3. Recommended: accept for v1, and revisit if writers pick the wrong column.
  4. The first seconds of a session. Until the first lazy menu chunk loads (the bubble's loads when the browser is idle), the style shortcuts in a list item or quote (⌘⌥0, ⌘⌥1–6) behave as on main today and do not unwrap the item. After that, every surface lifts only the selected items. This keeps the editor chunk at 0 B growth. Recommended: accept.
  5. Esc before the bubble's code has ever loaded. It does not cancel a bubble that is still waiting out its 250 ms delay. Fixing this needs eager code. Recommended: accept.
  6. Tablet stand-in words, option (b). Already chosen on 2026-11-22, shown in P4 as built. Touch tablets show “Format”, “Layout” and “Block” at every width from 768 px. Below 848 px, Redo moves to the top of ⋯ and the list button keeps only List ▾. No action unless the built version changes your mind.
  7. A known detail that is not a blocker. When ⋯ sits near the window edge, the Appearance submenu opens inward while its chevron points outward. main does this too. Recommended: a follow-up.

P1 · Selection bubble v2

The bubble gains the rest of its row: Style ▾ names the block in one word and opens Turn into; strike, inline code and clear formatting join B, I and U; colour opens named rows (Recent, then Text and Highlight side by side) instead of the swatch grid; and the link field takes focus in the click, so a pasted URL never lands on the selected words. The row's Text style ▾ shares the Turn into body, and the row's colour menus use the same named rows. On phones the Aa sheet keeps the swatch grid and names the current colour under it.

P2 · Quick insert

The “/” menu gets a Suggested section for your last three inserted kinds, a “Type to search” hint after the “/”, and a pinned footer that teaches the active row's Markdown shortcut and has a Close button. On a mouse or trackpad an empty line shows a + in the start margin that types the “/” for you. The empty-line placeholder becomes “Type / for blocks”. The menu is 320 px wide (was 288).
