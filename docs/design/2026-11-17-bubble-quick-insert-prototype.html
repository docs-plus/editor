O7 keyboard selection
Select text with the mouse to see the bubble. Alt+F10 (⌥F10) moves focus into it; arrow keys move; Esc returns with the selection. Put the caret on an empty line for +, or type /. ⋯ in the row › Page width changes the page. Phone: select text for the selection cells; Aa and Insert open sheets.

Prototype only. It approximates editor behaviour with contenteditable; the app uses Tiptap and the action registry. Colours are the app's tokens; icons are lucide 0.469 (the app's set). Today's bubble is shown for comparison under Version › Today.
